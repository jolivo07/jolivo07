### About me

I build backend systems that hold up under real-world complexity. My focus is software
architecture with **C# / .NET 8-9** — designing APIs, persistence layers, authorization
and synchronization workflows — and I build the interfaces on top with **React**.

Day to day that means Clean Architecture, DDD, CQRS and SOLID applied to real problems:
multi-tenancy, offline-first synchronization, JWT authorization, cloud storage and
deployment, from requirements through testing, documentation and production.

- 🔭 Currently building **UrbaniaSoft**, a multi-tenant property management platform on ASP.NET Core 9
- 🧩 Interested in domain modeling, system boundaries, and code that survives changing requirements
- 💼 Open to **Backend**, **.NET**, **Software Engineer** and **Full-Stack** roles — on site or remote
- 📄 [Résumé](https://jolivo.vercel.app/Joaquin_Olivo_CV.pdf)
